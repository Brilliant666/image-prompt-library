# 浏览器侧栏快捷收录

Chromium Manifest V3 扩展，使用 Chrome 原生侧栏。主动放入一张图片和对应的完整提示词，保存到已配对的本地 Image Prompt Library。正式资产仍由图库管理，扩展只保留当前卡片及必要回执。

## 本地加载

需要 Chrome 116 或更新版本，以及含“浏览器收录配对”功能的图库源码版本。扩展使用浏览器原生 JavaScript，没有 npm 依赖，也没有扩展打包步骤。

1. 打开 Chrome 的扩展管理页面 `chrome://extensions`，启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择仓库中的 `extensions/browser-capture` 目录。
3. 将扩展固定到工具栏，点击扩展图标打开原生侧栏。

源码检查命令（在仓库根目录执行）：

```sh
node --check extensions/browser-capture/sidepanel.js
node --test tests/browser-capture.test.mjs
```

修改扩展后，在扩展管理页点击“重新加载”，再关闭并打开侧栏。未完成卡片存于 IndexedDB；重新打开只恢复草稿，不自动提交。卸载扩展会删除其本地缓冲和配对信息，卸载前应处理未确认的请求。

## 首次连接

1. 启动含本功能的本地图库。侧栏初始地址为隔离测试端口 `http://127.0.0.1:8013`，**不会自动改为或连接 8000**。需要其他实例时，手动填写其实际 localhost / 127.0.0.1 地址和端口。
2. 在侧栏的齿轮设置中点击“打开图库配对设置”。图库页面会带入本扩展 ID；核对后主动授权。
3. 将图库仅显示一次的配对包复制到侧栏。点击“连接图库”，允许该本地地址的访问权限。连接会校验图库实例和配对客户端身份，不会调用生图接口。
4. 在图库设置的“浏览器收录配对”中可以撤销该客户端。侧栏的“清除本机配对”只删除本扩展的凭据副本，服务端撤销仍需在图库执行。

凭据独立于生图 API Key / OAuth Token，不放入图库导出或云同步。它只允许收录、语言判断、连接检查和读取该客户端自身收录回执，不允许查看全部图库、读取供应商、生成图片、修改设置或删除资产。

点击连接后，按钮附近显示“正在检查配对”、连接结果或错误。连接检查及自身回执查询使用不创建资产的 POST；Chrome 扩展的 GET 可能省略 Origin，因此不能用于本插件的严格来源校验。服务端仍要求真实的配对 Origin、凭据及实例同时匹配，不接受缺失 Origin。若此前旧版连接返回配对无效，更新隔离服务并重新加载扩展后，可继续使用原配对包，无需重复授权。

## 收录

图片和提示词是仅有的必填内容，可以任意顺序放入：

- 从文件管理器拖入一张图片，或主动使用 Ctrl+V 粘贴剪贴板中的图片。
- 将完整提示词粘贴或拖入下方文本框。保留空白和换行，不翻译、不改写、不拼接聊天历史。
- 拖放或粘贴完成，且当前图文均有效、图库已连接时，仅自动提交一次。图片仍在读取、中文输入法正在组词或请求结果未确认时不会自动提交。
- 普通键盘输入、点击选择文件、纠正语言、重新连接和重新打开侧栏不会自动保存。可点击“保存到图库”或按 Ctrl+Enter（macOS 也支持 Command+Enter）。
- 语言默认自动判断，结果不确定不会阻止保存。“纠正语言”中可手动选择；手动选择优先。
- 成功后显示缩略图和回执，可“在图库查看”或“继续收录”。继续会同时清空图片和提示词，不沿用上一条原文。

仅支持解码成功的 PNG、JPEG、WebP、GIF，单文件不超过 30 MB / 1,600 万像素。上传保留实际取得的文件字节和透明度。成功后仅在本扩展留下小缩略图及回执，原始图片缓冲和提示词副本被清除。

## 网页图片与权限

网页拖图可能提供 File、data URL、HTTP(S) URL 或临时 blob URL，提供 URL 不代表扩展已取得图片。

- **File / 剪贴板图片**：直接检查真实字节和解码，最可靠。剪贴板本身可能由浏览器提供转换过的版本，扩展不会将其宣称为平台原图。
- **data URL**：只接受受支持图片类型并检查字节和解码，不执行 HTML 或脚本。
- **公共 HTTP(S) URL**：点击“授权下载这张图片”才请求该图片网站权限。仅 GET 这次明确投递的地址，拒绝重定向，设置 20 秒超时和流式大小上限，不发送 Cookie、图库令牌或供应商凭据。拒绝字面本地 / 专用 / 保留 IP 和常见本地域名；扩展没有服务器网络代理。
- **blob / 登录态图片**：仅在用户点击“从当前标签页获取”后，借助 `activeTab` 权限读取该页面中地址完全相同的可见图片。同源请求可由浏览器使用该页面自身登录态；不提取、不导出 Cookie / Token，也不调用平台内部生成接口。当前页无授权、跨源、临时地址失效或无法取得时，请使用“复制图片”或拖入下载的文件。

从网页取得的始终是网页提供的可访问版本，不承诺平台下载原图。HTML 拖放只从不挂载、不执行的 template 中读取单个图片地址；多图投递会被拒绝。图片 URL 不会被自动当作提示词。

清理已授予的图片网站权限，可在齿轮设置中选择“移除已授予的图片网站权限”。Manifest 的网站范围是**可选权限**，安装时不授予全部网站读取能力；Chrome 的网站权限按主机匹配，无法细分 localhost 的端口，扩展自己的请求仍严格限制到配对包中的实际端口。没有常驻内容脚本、Cookie 权限、历史记录权限、剪贴板监听或云同步。

## 失败与恢复

提交前，图文、语言、目标实例、客户端 ID 和 request_id 一起冻结并写入 IndexedDB。网络断开、超时或关闭侧栏后：

- 卡片保持锁定；重新打开不自动重发。
- 点击“恢复回执 / 重试原请求”时先检查自己的收录回执；没有回执时才使用同一 ID 和完全相同内容重试。
- 明确的内容校验错误允许修改；请求冲突、网络错误和授权错误保留冻结内容，避免重复入库。
- 重新配对会产生新的客户端身份。未确认卡片不能改用新客户端重发，应恢复原配对或先到图库核对。这能避免服务端按客户端分隔请求 ID 时产生重复记录。
- 可以明确清除当前草稿；对结果未确认的请求会提示先核对图库。清除草稿不是删除已经创建的图库记录。本版不提供删除 / 撤销资产权限。

同时打开多个 Chrome 窗口的侧栏时，只有第一个窗口能编辑当前卡片，其余窗口只读。关闭原侧栏后，重新打开另一个侧栏即可接管。

## 验证边界

自动回归覆盖生产事件监听器、异步存储、两种图文顺序、重复事件、连续收录、普通输入 / 中文输入法、断网恢复、固定请求重试、凭据隔离、权限和大小边界。事件适配器测试不等于真实 OS 拖放或 Chrome 原生侧栏验收。

请用隔离图库和合成图片先验收：扩展实际加载与侧栏打开、首次配对、文件拖入、图片 Ctrl+V、选中文字拖入、公共图片权限提示、网页 blob 回退、关侧栏再恢复、撤销授权。具体运行记录和未验证项以当前 PR 的交付报告为准，不应把仅通过单元测试的输入方式写成已实测。
